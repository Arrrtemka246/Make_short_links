# Обрезка ссылок с помощью VK

Скрипт для сокращения длинных ссылок и получения статистики переходов по коротким ссылкам через VK API.

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта
2. Убедитесь, что у вас установлен Python 3.x
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

Рекомендуется использовать [virtualenv/venv](https://docs.python.org/3/library/venv.html) для изоляции проекта.

## Настройка

1. Получите токен доступа VK API
2. Создайте файл `.env` в корневой директории проекта
3. Добавьте в файл `.env` ваш токен:

```
VK_API_TOKEN=ваш_токен_доступа_vk_api
```

## Использование

### Способ 1: Через аргументы командной строки

```bash
python main.py https://example.com/very-long-url
```

### Способ 2: Интерактивный ввод

```bash
python main.py
```
Затем введите ссылку по запросу программы.

## Примеры работы

### Сокращение ссылки:
```
Введите ссылку: https://example.com/very-long-and-complicated-url
https://vk.cc/xxxxx
```
